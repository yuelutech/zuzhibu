1. 停两个计划任务，免得切换中途推送：

   ```powershell
   Disable-ScheduledTask -TaskName 'AI政见组织部-一局每日更新'
   Disable-ScheduledTask -TaskName 'AIpolis-人事三局重核'
   ```

2. 用 main 的文件建只有一个提交的新仓库，不带任何旧历史：

   ```powershell
   git -C '<工作目录>' archive --format=zip -o "$env:TEMP\zuzhibu-main.zip" main
   Expand-Archive "$env:TEMP\zuzhibu-main.zip" -DestinationPath '<新目录>'
   git -C '<新目录>' init -b main
   git -C '<新目录>' add -A
   git -C '<新目录>' -c user.name=yuelutech -c user.email=271875645+yuelutech@users.noreply.github.com commit -m "AI政见·组织部 首次公开"
   ```

3. 在新仓库里复查，应当全部通过，署名只有无回复地址：

   ```powershell
   Set-Location '<新目录>'
   python -m unittest discover -s tests
   python tools/guard.py --release
   git log --format='%an <%ae>'
   ```

4. GitHub 上，维护者本人操作：
   1. 现仓库 yuelutech/zuzhibu：Settings → General 改名为 `zuzhibu-archive`，再点 Archive this repository，保持私有。
