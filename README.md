# AI政见·组织部

美国政要干部简历资料库

## 一、基本情况

AI政见·组织部是 Yuelu Tech“AI政见”推出的开源桌面软件。软件坚持实事求是、客观准确的原则，按照干部简历的规范体例，系统整理美国白宫、商界、国会、国防、司法系统主要负责人的公开资料，集中收录人事任免动态，为研究美国政治、经济、军事和司法体制提供基础资料。

## 二、主要内容

（一）干部简历资料库。分五个栏目，按机构和职务层级逐级编排。

1. 白宫。总统，副总统，国务卿、国家安全事务助理、白宫办公厅主任，内阁成员。
2. 商界。美国上市公司市值前二十五位企业和主要人工智能企业的主要负责人。
3. 国会。参众两院领导，全体参议员、众议员和无表决权代表。
4. 国防。国防部长、参谋长联席会议主席，各军种主要负责人，各联合作战司令部司令。
5. 司法。最高法院首席大法官，司法部长，最高法院大法官，主要金融和市场监管机构负责人。

（二）人事动态。收录美国联邦政府、国会、军队、司法机关和主要企业的人事任免，逐条核实后发布，同步更新有关人员简历。

## 三、编纂原则

（一）坚持依据权威来源。资料以官方网站、政府公报、国会文件、监管机构披露文件等一级来源为依据，逐条核实，做到每项事实有据可查。

（二）坚持规范统一。简历统一按照干部简历体例编写，人名、地名、机构名统一采用规范译名。

（三）坚持客观中立。只记录事实，不作评价；资料缺项如实留空，不作推测。

## 四、安装使用

（一）系统要求。Windows 10、Windows 11（64 位）。

（二）安装。从本项目发布页下载最新安装包，按提示完成安装，不需要管理员权限。

（三）资料更新。维护者每月更新一次资料，软件联网后自动获取。需要随时更新人事动态的，可在“设置”中填写本人的大模型接口，所用额度由本人账户承担。本项目不提供、不共享任何账号和密钥。
