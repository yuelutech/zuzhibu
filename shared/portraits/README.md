# portraits（头像处理规则）

本目录放头像规则。软件用的照片在 `data/portraits/`：名单里的人是蓝白渐变底 3:4 头肩标准像，600×800（`docs/PRODUCT.md` 第三节；抠图、换底在仓库外用维护者本机的工具做，仓库只放成品），名单外的人保留早先的 300×400 小图。来源和许可登记在 `data/portraits/index.csv`，登记的是原图的来源和许可，换过底的注明“已换蓝白渐变底”；原图留在维护者本机，不进仓库。`sources.csv` 是早期的登记表，已不用。

- 来源：只用可核验来源的真实照片，例如官方页面和官方肖像。生成图一律不用。
- 登记：每张小图在 index.csv 里登记来源、来源链接、许可、处理方式和日期。许可一栏开头写结论：`公有领域`、`CC BY …`（写明作者）、`待核`、`版权保留`或`来源不明`，冒号后写依据。转公开时只留公有领域和 CC BY 的，`tools/guard.py --release` 会查（`docs/公开前检查.md` 第十节）。
- 重新抠图后是否采用，沿用 Care 历史项目 idphoto_batch 的阈值。gap 指主体下方留白占画面高度的比例。只有旧图 old_gap > 0.05、且新图 new_gap < 0.045 时才换成新图；旧图 old_gap 不超过 0.05 的不动，避免把好图改坏。
