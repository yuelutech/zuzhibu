## 和母本同步

三张 v1.4 表是母本的副本，只做两处替换：维护者姓名换成“AI政见”（decided_by 和备注里的都换），换行统一成 LF（`.gitattributes` 规定）；其余逐字节相同。母本不改。

母本更新后这样同步，`--check` 只比对、不写：

```
python tools/sync_glossary.py --source <母本目录> --name <维护者姓名>
python tools/sync_glossary.py --source <母本目录> --name <维护者姓名> --check
```

改译名先改母本再同步。直接改了副本的，要把同样的改动补进母本，不然下次同步会被盖掉；`--check` 能查出两边不一致。维护者姓名只在命令行给，不写进仓库。`补充译名_person.csv` 和 `译名表使用说明.md` 不在同步范围内，在本仓库里直接改。
