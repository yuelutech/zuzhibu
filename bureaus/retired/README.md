# retired（七局·老干部局）

接收已经离任或被免职、没有其他现任职务、也没有新职务单位的人物，保留完整历史履历。

- 没有首发名单。人物只由一局的动态迁入：`zuzhibu/personnel.py` 写回离任或逝世动态时，记录里已无现任职务、核实结果明确没有其他现职、明确没有公布新任命，三条都满足才转入。
- 转入后沿用同一份人物记录（`data/people/`），履历、来源、历次动态和归属记录都保留；`bureau` 改为 `retired`，`bureau_history` 记一条。
- 七局人物重新任职时，一局写回新任命，按新职务转回对应业务局。
- 本目录只放说明，没有名册原料。
