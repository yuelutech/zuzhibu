# 人事动态补查（2026-08-01 至 2026-10-18）

分两个任务，范围原文见 `bureaus/dispatch/research.py` 的 `SCOPES`：

- `dongtai-zhengfu`：三局（白宫、内阁、独立机构、驻外大使）、五局（美军）、六局（公检法）。
- `dongtai-ai`：二局（人工智能和科技企业、研究机构、投资机构的领导人物）。

结果只写进 `inbox/codex/<任务名>/`。文件格式和规矩见 `inbox/README.md`。

## 做什么

1. 把这段时间范围内的任免查全：逐月过一遍。
   - 政府：whitehouse.gov 的任命和提名公告、congress.gov 的提名和参议院确认记录、联邦公报、各部和独立机构新闻稿、war.gov 和各军种将官任命公告、司法部和最高法院新闻。
   - 二局：公司新闻稿、证券交易委员会 8-K（Item 5.02 高管和董事变动）、主流科技媒体。二局只收库里的人和库里机构的领导层变动，库外只收主要人工智能公司和顶级风投的首席执行官、总裁、董事长、联合创始人、首席技术官、首席科学家一级。
2. 库里已有的动态（`data/events/2026-08/` 至 `2026-10/`）不重复报。库里动态有错的，在 README 里列出：动态编号、错在哪、正确的写法和来源。
3. 库里人物的现任职务已经不对的（离任、换岗），一律报动态，库里有的人 `person_id` 填编号（`python tools/gaps.py --bureau <局>` 查编号）。
4. 离任、逝世的，查清其他现职和新任命（见 inbox/README.md 的 events.json 一节），这决定此人能不能转七局。

## 产出

- `events.json`：每条有来源，原文摘句照抄。
- `names.csv`：库外新人里译名表没有中文名的。
- `README.md`：查了哪些来源、哪些月份；各局各多少条；库里动态的错误清单；拿不准、没报的线索。

## 完成标准

`python tools/inbox.py check inbox/codex/<任务名>` 错误为 0；README 写明 8、9、10 三个月都查过。
